# **App Name**: J.A.R.V.I.S X

## Core Features:

- Neural Agent Orchestration: A Master Agent functions as a cognitive tool, intelligently routing complex tasks across a multi-agent mesh for specialized processing in coding, research, or system control.
- Holographic Voice Interface: Full-duplex voice interaction featuring an animated Voice Orb, sub-second Speech-to-Text via Faster-Whisper, and ultra-natural Piper TTS audio synthesis.
- Recursive Long-Term Memory: Utilizes ChromaDB and pgvector for semantic association, allowing the intelligence to utilize the user's past interactions as a reference tool for future decisions.
- Autonomous Automation Engine: Native integration with Playwright and PyAutoGUI, enabling the agent to function as a digital tool capable of managing browser navigation and local file operations.
- System Health Matrix: A high-fidelity dashboard for real-time monitoring of local LLM metrics including VRAM utilization, GPU performance, and active agent workflow logs.
- Spatial Vision Recognition: A vision-enabled intelligence layer that uses screenshot capture and LLaVA-based visual reasoning tools to perceive and explain the user's active workspace.
- Central Messaging Terminal: An interactive, glassmorphism-styled command center that renders real-time WebSocket token streams and structured agent feedback cycles.

## Style Guidelines:

- The palette is inspired by deep space instrumentation. Primary color is an electric Periwinkle Blue (#8282F2). The background is a dense Charcoal Carbon (#14141F). The accent is a high-contrast Sapphire (#1769CC) to distinguish interactive elements.
- A precision-focused font pairing of 'Space Grotesk' (Sans-serif) for high-impact headlines and 'Inter' (Sans-serif) for high-density interface data and chat history.
- Technical, wireframe-style linear icons with fine 1px strokes that mirror professional engineering software aesthetics.
- A command-center inspired modular grid utilizing glassmorphism overlays and heavy usage of semi-transparent backdrop-filters for depth.
- Bespoke Framer Motion transitions simulating digital boot sequences, glowing pulse states for the Voice Orb, and smooth logarithmic layout shifts.
